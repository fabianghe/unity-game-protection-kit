# Security policy

## Reporting a vulnerability in this package

If you find a way this package could harm players or developers, for example:
- legit players getting flagged,
- a crash or exploit through the notice or checks,
- a data leak,

please report it privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue. You'll get a response as soon as possible.

## Please don't post bypasses

Don't post step-by-step bypasses of these checks for specific shipped games in issues or discussions. General discussion of weaknesses, with improvements, is welcome. Detection that only catches lazy thieves is still worth having, and we'd like to keep it that way.

## Scope

This package is detection and build hygiene, not DRM. "A determined attacker can patch the check out" is a known limitation, not a vulnerability.
